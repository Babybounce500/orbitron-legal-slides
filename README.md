# ORBITRON Legal Slides

21 Gamma-generierte Präsentations-Decks (je 10 Folien, Deutsch) für die
ORBITRON LEGALTECH-Plattform — Tool-Decks, Fachbot-/Plattform-Übersicht,
Onboarding-Tutorial und Vertriebs-Pitches (allgemein + für Kanzleien).

Gehostet hier statt direkt in der App, da der Gesamt-Upload (~25 MB) das
Replit-Upload-Limit überschreitet. Die Workshell in der App verlinkt
diese Dateien über absolute `raw.githubusercontent.com`-URLs.
